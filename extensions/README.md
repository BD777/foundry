# Connector extensions kept in Foundry

Official connector extensions for tools Foundry supports from the outside,
through their public command line or a generic server-held gateway
([docs/connector-extensions.md](../docs/connector-extensions.md)).
These folders ship with the Worker. Install one on a device from Connectors;
there is no repository address to enter:

    foundry-worker extension add <path to the Worker's extensions/limen folder>
