# DEV-332 等你处理：一条只说一遍、记得起来是什么事、三种关闭方式、回复框即对话输入框

本人 2026-11-24 看「等你处理」：一条转交的问题整段文字出现三次、看不出上下文；「完成」藏在菜单里、没有「已放弃」；跳到消息常常到不了；回复框是纯文本框。另见同日侧栏改动（PR #314，「我的」一栏：等你处理、事项）。

## 问题与原因

| 现象                             | 原因                                                                                    |
| -------------------------------- | --------------------------------------------------------------------------------------- |
| 同一段问题出现三次               | 标题（截断加「…」）、转交说明、摘录各自显示；去重只比较完全相等，截断的标题和全文对不上 |
| 选项写在正文里（回复 A / B / …） | 助理的 handoff skill 写明转交时给 2–4 个选项，但 `needs_you hand_over` 不接受 options   |
| 想不起是什么事                   | 卡片只有助理的转述；起因（本人的原话、在哪说的）没有呈现                                |
| 「你」「我」指谁不清             | 助理写的转交说明没有标明说话人                                                          |
| 关闭帮手的提问后帮手一直在等     | 本人关闭只改状态，不告诉在等答复的帮手                                                  |
| 跳到消息到不了                   | 对话只加载最新 200 个事件；链接指向更早的消息时没有任何加载，也没有提示                 |
| 回复不能带附件、不能用 skill     | 回复框是独立的 Textarea，没有复用对话输入框                                             |

## 改动

- 卡片：截断标题的全文（转交说明或摘录）只出现一次，作为正文，夹紧 4 行可展开；转交说明另有内容时才显示「助理：」块，否则元信息行写「助理转交给你」；助理写的正文前标「<助理名>：」。
- 起因行：开着的条目显示本人最后一次说的话（帮手看派发它的会话，否则看条目所在对话），以及在哪说、何时说（消息通道的会话名；或 Foundry 对话）。从会话记录读出，不经模型（`pending_origin.go`）。
- 关闭：「完成」「放弃」「不需要我」并列；新增状态 `abandoned`（结果 `person_abandoned`），与另外两种一样保留在「已解决」。关闭助理帮手正在等的提问时，经帮手收件箱送去无答复回复并说明是哪一种（重复关闭不重复发送）；本人自己的对话不发。
- `needs_you hand_over` 新建条目时可带 2–4 个选项（推荐项以「（推荐）」标出），网页与飞书卡片显示为按钮；`ask` 也记录推荐项。
- 分组标题带来源图标（对话、Issue、事项、助理）；名称重复时只显示一次。
- 回复框改用对话的输入框（附件：选择、粘贴、拖入；「/」列出目标对话的 skill；Enter 发送，Esc 先关菜单再关回复）。输入框的附件处理抽成共享的 `AttachmentComposer`；「/」菜单宽度不超过所在输入框。以 skill 开头的回复，回复在前、引用在后。
- 跳到消息：`GET /api/agent-sessions/{id}?eventsBefore&eventsThrough=<消息 id>` 一次读到该消息（另见 jump PR）；消息已不在时提示。

## 限制

- 分组标题仍是帮手会话的标题（会话中途换了任务时会过时）。
- 正文仍是助理写的一段话；有选项时选项单独成按钮，其余措辞由助理决定。
- 回复 Issue 提问、助理自己的提问、事项等待时仍只能发文字（这些答复接口不收附件）。
- 跳到极早的消息时一次读取的事件较多（与滚动到那里加载的量相当）。

## 验收

1. 打开「等你处理」，一条由助理转交的长问题：正文只出现一次，前面写着助理名；下面一行是你的原话和出处。
2. 点「放弃」：条目进入「已解决」，状态「已放弃」；对应帮手对话里收到无答复回复并停止。
3. 点「回复」：输入框与对话相同，可加文件，输入「/」列出该对话的 skill；Esc 先关菜单再关回复。
4. 点「跳到消息」到一条较早的消息：对话定位并高亮该消息。
