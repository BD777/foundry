# DEV-163 · 表格弹窗与回答预览

## 问题

宽表在回答正文里只能横向滚动，难以阅读或复制；图片和长回答也缺少不离开会话的快速预览。表格复制只得到渲染文本，Dialog 的宽度在小屏和长标题下不稳定。

## 调查与修复

- 表格可打开共享 Dialog 预览，并支持复制原始 Markdown；截图使用 `modern-screenshot` 生成预览资源。
- 回答提供预览入口，沿用现有 Markdown 渲染和本地图片处理，不建立第二套内容格式。
- Dialog 宽度改为受视口约束的稳定尺寸，内容区负责滚动，小屏不溢出；此处以部署状态 D 的共享 Dialog 实现为准。
- 补齐中英文文案、Markdown、表格、图片和回答预览测试，并更新依赖锁文件。

## 部署与版本证据

该改动的 Web 与依赖部分属于 dev 已部署状态，已纳入 2026-11-10 部署状态快照 D；Dialog 文件取 D 的最终版本。

## 检查

- Web TypeScript typecheck
- `chat-markdown.test.mjs`
- `local-image.test.mjs`
- `answer-preview.test.mjs`
- 真实 Chromium 检查宽/窄屏、浅/深色、键盘关闭和横向溢出

## 限制

本次为提交窗口本地演练，不推送、不创建 PR。截图依赖浏览器能力，失败时应保留可读表格与复制操作。

## 验收步骤

1. 在回答中打开宽表，应出现受视口约束的弹窗，内容和操作不重叠。
2. 点击复制 Markdown，粘贴结果应是原始表格语法，而不是渲染后的单元格文本。
3. 打开长回答或图片预览，滚动应发生在内容区，关闭后焦点回到触发按钮。
