# DEV-167 · 窄屏全局导航

## 问题

窄屏下全局侧栏收起后，主要页面之间缺少持续可发现的切换入口，用户容易困在当前视图。

## 调查与修复

- AppShell 在窄屏提供固定的全局导航，保持当前页选中态，并为内容预留安全区。
- 导航项沿用共享视觉与无障碍语义，支持键盘、焦点、禁用和忙碌状态。
- 侧栏在宽屏保持既有平铺分组；Dialog 继续使用部署状态 D 的共享实现，不把导航改动混进弹窗内部。
- 中英文 shell 文案与窄屏 scope 测试同步更新。

## 部署与版本证据

该改动属于 dev 已部署状态，已纳入 2026-11-10 部署状态快照 D。

## 检查

- Web TypeScript typecheck
- `sidebar-scope.test.mjs`
- 真实 Chromium 在 390px 与桌面宽度检查导航可见性、选中态、键盘和内容区无遮挡

## 限制

本次为提交窗口本地演练，不推送、不创建 PR。视觉验收仍需在完整页面和正常缩放下复核。

## 验收步骤

1. 在 390px 宽打开任一主要页面，底部或窄屏导航应持续可见。
2. 当前页面应有明确选中态，其他入口可用键盘切换。
3. 内容滚动时导航不得覆盖可操作控件，桌面宽度应恢复既有侧栏。
