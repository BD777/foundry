# DEV-160 · Assistant 设置重设计与共享导航

## 问题

Assistant 设置原先用一长排分段控件承载多个分区，宽屏没有持续可见的章节导航，窄屏又难以从长页面回到其他分区。

## 调查与修复

- 设置路由现在可以只打开 `/assistant/settings` 的索引；选择具体分区后使用独立地址，浏览器前进/后退保持当前分区。
- 宽屏使用固定分区侧栏，窄屏使用可扫描的分区目录；每项是真实链接，支持键盘、新标签页和历史导航。
- 新建共享 `NavList`，让应用侧栏与页面内分区使用同一组条目样式、当前态和无障碍结构。
- 同步更新中英文文案、Assistant 设置测试和路由测试。

## 部署与版本证据

该重设计属于 dev 已部署改动，已纳入 2026-11-10 部署状态快照 D。

## 验收步骤

1. 打开 `/assistant/settings`。宽屏应显示按组排列的分区侧栏；窄屏应显示分区目录。
2. 选择“模型”或“记忆”，地址应指向对应分区，浏览器后退应回到索引或上一分区。
3. 当前分区应有明确选中态，键盘和普通链接行为一致。
